# App Giao Hàng & Đánh Giá Tài Xế (Fuzzy Logic)

## Giới thiệu
Dự án sử dụng Logic mờ để tính toán thời gian giao hàng, tiền thưởng và xếp hạng tài xế dựa trên các yếu tố: Giao thông, Khoảng cách, Thời tiết và Độ mệt mỏi.
